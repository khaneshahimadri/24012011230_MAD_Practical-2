## ⚙️ How to Run the Project

1. Clone this repository:

```bash
git clone https://github.com/khaneshahimadri/24012011230_MAD_Practical-2.git
```

2. Open **Android Studio**.

3. Select **Open** and choose the cloned project folder.

4. Wait for the **Gradle Sync** process to complete.

5. Connect an Android device or start an Android Emulator.

6. Click the **Run ▶** button.

7. The application will be installed and launched on the selected device.
